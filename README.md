# specdog

> Feed the dog. Ship with specs.

[Guide](https://specdog.github.io/handbook) — spec-driven development with [type-driven design](https://specdog.github.io/handbook#type-driven-design): domain types, valid states, operation contracts, and checked runtime boundaries.

**[dotdog 1.0](https://specdog.github.io/dotdog)** — local-first spec/code graphs, saved REA/Ghidra call-graph traversal, and optional TypeScript contract inspection. [npm](https://npmjs.com/package/dotdog) | [Release notes](https://github.com/specdog/dotdog/releases/tag/v1.0.0) | [Migration](https://specdog.github.io/dotdog/v1-migration)

Run from your repository with npm: `npx dotdog@1.0.0 refresh --json`, or Bun: `bunx --bun dotdog@1.0.0 refresh --json`. Node.js 22.12+ or Bun 1.3+; the optional type adapter additionally requires Node and a trusted project-installed TypeScript 7.0.2 compiler.

**[dogbench](https://specdog.github.io/dogbench)** — token-savings benchmark for Collar and dotdog. [GitHub](https://github.com/specdog/dogbench)
