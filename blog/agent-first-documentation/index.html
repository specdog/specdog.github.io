Agent-First Documentation — The New Standard

Documentation is now runtime context for agents as well as a handoff between humans. It needs stable names, clear entry points, and links that make project intent easy to find.

Agent-first documentation keeps the readable explanation, but removes ambiguity around what exists and where it lives.

For specdog projects, that means the public site, guide, agent page, and product pages should agree on the same names and routes.
