Dotdog / Homebrew

A separately maintained distribution; verify the formula version before installing.

brew tap specdog/dotdog
brew install dotdog
dotdog --version

The existing formula pins Dotdog 0.3.5. It is not the 1.0 distribution. For current Dotdog 1.0 use npm or Bun; do not assume the tap has been upgraded.

What this does

Downloads dotdog from npm. Installs globally via Homebrew. Depends only on Node.js.
