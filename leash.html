leash

Open-source, safety-gated Rust runtime for robots, operators, and AI agents.

Core rule: an agent or operator can request motion; Leash decides whether motion is allowed.

Current main

Leash is now a multi-crate robotics workspace with one shared capability and safety boundary across CLI, HTTP, WebSocket/SSE telemetry, MCP stdio, and MCP Streamable HTTP.

Safe local developmentSimulation, deterministic replay, record/replay JSONL, schemas, and no-hardware smoke tests.

Try it safely

cargo install leash-harness
leash run sim-http

In another terminal:

leash health --url http://127.0.0.1:8000
curl -s http://127.0.0.1:8000/telemetry | jq
leash agent-send "inspect the battery"

Or expose the simulation runtime through MCP:

leash run sim-mcp

# or localhost MCP HTTP
leash serve mcp-http --listen 127.0.0.1:9990
leash mcp list-tools
leash mcp call observe

These default paths do not touch physical hardware.

Agent workflows

Current main can persist model sessions, run a browser console, invoke typed capabilities with allow/deny rules, and supervise recurring capability tasks.

leash agent run "summarize current health" --session demo
leash agent sessions list
leash agent headful --no-open
leash agent capability call health --allow health

Agent requests still pass through the same capability registry and safety policy as CLI, HTTP, and MCP requests.

Safety boundary

Physical motion is fail-closed. Mapping, localization, planning, ROS 2, CUDA, model providers, and external agents can supply requests or evidence, but they do not bypass Leash's final command policy.

Physical paths remain subordinate to explicit compile/runtime gates plus authorization, approval, sensor/provider freshness, deadman, collision checks, soft odometry limits, Stop, and E-Stop.

Open source

Humans

Clone the repository, work from current main on a branch, and use simulation first:

git clone https://github.com/specdog/leash.git
cd leash
npm ci
cargo build
cargo run -- run sim-http

Before merge, contributors run formatting, workspace Clippy/tests, Node tests, schema checks, packaging, and the aggregate smoke suite. Hardware changes must stay feature-gated and require real evidence for physical claims.

Human contribution guide

Agents

Coding agents start at the repository-root AGENTS.md. For project/spec structure, agents query the compiled DotDog graph rather than reading human .dog source:

npm ci
npx dotdog serve

specs/leash/leash.dag is the agent graph. Current code, tests, schemas, and merged docs on main define implementation behavior. If graph and code disagree, agents report the drift instead of inventing structure.
